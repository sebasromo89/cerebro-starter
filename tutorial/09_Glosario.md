# 09 · Glosario de palabras raras

Vas a ver estas palabras en pantalla. No necesitas dominarlas; aquí está qué significan.

| Palabra | Qué significa en tu vida |
|---|---|
| **Cerebro** | Tu carpeta de trabajo, la que tu asistente lee para conocerte |
| **Frente** | Un área de tu trabajo, con su carpeta propia |
| **Receta / skill** | Un comando que hace una tarea completa (`/minuta`, `/cerrar-dia`) |
| **Conector** | El permiso para que tu asistente lea un sistema (correo, calendario) |
| **VS Code** | El programa donde ves tu carpeta y hablas con tu asistente |
| **Repositorio (repo)** | Una carpeta que guarda su historial de versiones. Tu cerebro es un repo |
| **GitHub** | La nube privada donde se respalda tu repo |
| **Git** | El programa que guarda las versiones. Trabaja por detrás |
| **Commit** | Una "foto" guardada de tus archivos en un momento, con una nota de qué cambió |
| **Push** | Subir esas fotos a la nube |
| **Pull** | Bajar de la nube lo último (por ejemplo, lo que guardó tu equipo) |
| **Clonar** | Bajar una copia completa de un repo a tu computadora, la primera vez |
| **Plantilla (template)** | El molde del que sacaste tu copia |
| **Choque de versiones (conflicto)** | Dos personas cambiaron lo mismo a la vez. Se resuelve juntando ambos cambios |
| **Markdown (.md)** | El formato de casi todos los archivos del cerebro: texto simple con títulos y tablas |
| **`CLAUDE.md`** | El archivo principal de tu cerebro: lo primero que lee tu asistente |
| **`.env`** | El archivo donde se guardan contraseñas y llaves. Nunca se sube a la nube |
| **Hook** | Una acción automática, como el guardado al terminar cada tarea |
| **Contexto** | Lo que tu asistente tiene "en la cabeza" en una conversación. Se llena; tu cerebro no |
| **`/clear`** | Empezar una conversación nueva |
| **`/compact`** | Resumir la conversación para seguir en lo mismo sin llenarla |
| **Terminal** | Una ventana de texto para darle órdenes a la computadora. Tu asistente la usa; tú casi nunca |
