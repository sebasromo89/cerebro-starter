# Dónde va cada cosa

| Qué es | Dónde va |
|---|---|
| Lo que sabes de la persona, sus reglas y sus decisiones | `cerebro/` |
| Todo lo de un área de trabajo | `frentes/NN_Nombre/` |
| Pendientes de un frente | `frentes/NN_Nombre/Backlog.md` |
| Minuta de una reunión | `frentes/NN_Nombre/Minutas/AAAA-MM-DD Tema.md` |
| Transcripción completa de una reunión | `frentes/NN_Nombre/Minutas/transcripciones/AAAA-MM-DD Tema.md` |
| Documentos de trabajo de un frente (propuestas, guías, análisis) | `frentes/NN_Nombre/Documentos/` |
| Entregables generados (presentaciones, PDF, páginas, tableros) | `frentes/NN_Nombre/Entregables/` |
| Resumen de cada día | `cerebro/bitacora/AAAA-MM-DD.md` |
| Algo que llegó y no sabes de qué frente es | `bandeja/` (se reparte en el `/cerrar-dia`) |
| Recetas (comandos) nuevas | `.claude/skills/<nombre>/SKILL.md` |
| Scripts que ejecutan algo mecánico | `herramientas/` |
| Reglas nuevas que el asistente debe cumplir solo | `.claude/rules/` |
| Videos, audios y archivos pesados | En la nube de la persona (OneDrive, Drive, SharePoint), con la liga en el `.md` |

Si algo no encaja en ninguna fila, pregunta antes de crear una carpeta nueva. Si la respuesta se va a repetir, agrega la fila a esta tabla.
